# Excel-проекты: анализ данных и финансовая аналитика

В этой папке собраны мои работы в Excel, демонстрирующие навыки работы с данными, построения сводных таблиц, визуализации и финансового моделирования.

Все проекты выполнены в рамках учебной и самостоятельной работы.

---

## 1. Анализ поставок и логистики по регионам

**Файл:** `Анализ_поставок_и_логистики_по_регионам.xlsx`

**Задача:**  
Проанализировать поставки продуктов от трёх поставщиков в четыре региона (Юг, Север, Запад, Восток). Оценить своевременность поставок, остатки и общую стоимость товаров.

**Что сделано:**
- Собраны данные по 30+ продуктам для каждого региона.
- Рассчитаны остатки товаров (25% от поступивших).
- Определён статус доставки (в срок / просрочена) на основе сравнения фактической и плановой дат.
- Подсчитана общая стоимость товаров по каждому региону и поставщику.
- Построена сводная таблица по поставщикам: общее количество поставленного товара.
- Выделен отдельный анализ по продукту "Яблоки" в разрезе регионов.

**Результаты:**
- Выявлены поставщики с наибольшими объёмами поставок.
- Определены регионы с наибольшим количеством просроченных поставок.
- Рассчитана общая стоимость товаров в каждом регионе.

**Навыки:** сводные таблицы, функции `IF`, `INT`, работа с датами, группировка данных.

## 2. Дашборд прибыли и продаж по магазинам

**Файл:** `Дашборд_прибыли_и_продаж_по_магазинам.xlsx`

**Задача:**  
Проанализировать прибыль и продажи косметических товаров в 4 магазинах. Оценить вклад каждого поставщика и типа товара в общую выручку. Визуализировать ключевые показатели.

**Что сделано:**
- Сгенерированы данные по продажам косметики (бренды, типы товаров, объёмы, цены, поставщики).
- Рассчитана прибыль с каждого товара (цена × количество проданных единиц).
- Построены сводные таблицы:
  - Общая прибыль по магазинам.
  - Прибыль по поставщикам в разрезе магазинов.
  - Количество проданных товаров по типам и поставщикам.
- Визуализированы данные в виде диаграмм (гистограммы, круговые диаграммы).

**Результаты:**
- Выявлены самые прибыльные магазины (Запад — 10,2 млн ₽, Восток — 8,3 млн ₽).
- Определены ключевые поставщики (ИП Иванова и мир красоты).
- Понято, какие типы товаров приносят основную выручку (помада, хайлайтер).

**Навыки:** сводные таблицы, диаграммы, группировка данных, дашборды.

## 3. Финансовый калькулятор: ИП vs Физлицо

**Файл:** `Финансовый_калькулятор_ИП_или_Физлицо.xlsx`

**Задача:**  
Сравнить затраты компании при оформлении сотрудника как физическое лицо (с НДФЛ 13% и страховыми взносами 30%) или как индивидуальный предприниматель (без налогов и взносов).

**Что сделано:**
- Для физлица рассчитана официальная зарплата на основе желаемой суммы "на руки".
- Посчитаны налог, страховые взносы и общие затраты компании.
- Для ИП затраты компании равны желаемой сумме.
- Рассчитана разница в затратах между ИП и физлицом.
- Добавлены пояснения с пошаговым расчётом для наглядности.

**Результаты:**
- При найме физлица с зарплатой 35 000 ₽ на руки компания тратит ~52 300 ₽.
- При найме ИП с той же суммой компания экономит ~17 300 ₽.
- Калькулятор позволяет быстро подобрать нужную сумму для любого варианта.
