## Структура портфолио

### 1. [financial-investment-analysis-tool](./financial-investment-analysis-tool)
**Система оценки инвестиционных рисков**

Комплексный проект по анализу, проектированию и разработке программного средства для автоматизации оценки инвестиционных проектов малого бизнеса.

**Что внутри:**
- Анализ предметной области (требования, действующие лица, процессы)
- Техническое задание 
- UML-диаграммы 
- Проектирование базы данных (ER-диаграммы, SQL-код)
- Архитектура ПО и компонентная структура
- Тест-кейсы, чек-листы, баг-репорты


**Стек:** Python, PyQt6, Pandas, SQLite, ReportLab

---

### 2. [excel-dashboard](./excel-dashboard)
**Excel-проекты: анализ данных и финансовая аналитика**

Три самостоятельных проекта в Excel, демонстрирующие навыки работы с данными, визуализации и финансового моделирования.

**Проекты:**
- **Анализ поставок и логистики по регионам** — оценка поставщиков, просрочек, остатков и стоимости товаров в 4 регионах.
- **Дашборд прибыли и продаж по магазинам** — анализ прибыли по магазинам, поставщикам, типам товаров с диаграммами.
- **Финансовый калькулятор: ИП vs Физлицо** — сравнение затрат компании на сотрудника.
