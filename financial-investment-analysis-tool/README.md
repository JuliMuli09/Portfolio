# Система оценки инвестиционных рисков

## О проекте
Автоматизация расчёта инвестиционных показателей (NPV, точка безубыточности, анализ рисков) с генерацией PDF-отчётов.

Что использовала:
- Python 3.10
- PyQt6
- Pandas и NumPy
- ReportLab
- SQLite
- PyCharm и Draw.io

## Содержание портфолио

- 01  Анализ предметной области 
- 02  Сравнительный анализ аналогов 
- 03  Техническое задание 
- 04  Функциональная структура системы 
- 05  Объектно-ориентированное проектирование (UML) 
- 06  Проектирование базы данных 
- 07  Архитектура и компоненты ПО 
- 08  Тестирование и чек-листы 
- 09  Баг-репорты 
- 10  Сводный отчёт и руководство пользователя 

## Результат
Разработана программа для оценки инвестиционных проектов с графическим интерфейсом и автоматической генерацией отчётов.
